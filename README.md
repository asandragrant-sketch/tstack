## 🚀 Getting Started

### Local Development
```bash
# Clone the repository
git clone https://github.com/asandragrant-sketch/tstack.git
cd tstack

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
